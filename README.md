# Kramer Browser

Kramer Browser is a lightweight browser built on Chromium.

<img width="512" height="512" alt="github kramer" src="https://github.com/user-attachments/assets/96901864-0751-41dc-adf6-53c79572678a" />


## Features

- Install extensions from the Chrome web store
- Supports multiple local profiles (no cloud sync)
- Supports bookmarks, history, etc.
- Kramer Search engine on the new tab page

## Install

Download the installer from [Releases](../../releases).
